# Projeto Oficina de Programacao

Aurora Coffee e uma loja virtual de cafe especial com blends, kits de preparo e acessorios para diferentes perfis de consumo.

## Estrutura

- `index.html`
- `pages/catalogo.html`
- `pages/produto.html`
- `pages/cadastro.html`
- `css/style.css`
- `imagens/`

## Conteudo do site

- Pagina inicial com apresentacao da marca e acesso rapido ao catalogo
- Catalogo com produtos como cafe classico, kit barista, prensa francesa e assinatura mensal
- Pagina de produto com foco no Kit Barista Aurora
- Area de cadastro para entrada no Clube Aurora
- Identidade visual inspirada em tons terrosos, crema e verde profundo
- Layout responsivo para desktop e mobile

## Como visualizar

1. Abra `index.html` no navegador.
2. Navegue pelo menu superior para acessar as demais paginas.
